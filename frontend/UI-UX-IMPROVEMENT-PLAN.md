# UI/UX improvement plan

## High priority
- Summarize error, warning, and info counts alongside the record count.
- Filter findings and related records by severity; show counts and a reset option. Keep document-level findings visible.
- Link findings and records in both directions, with severity indicators and temporary highlights. For duplicate address codes, show all possible matches unless a reliable record ID is available.
- Make issue messages actionable and distinguish address codes from issue types.

## Next, if time permits
- Search findings and records by code, message, issue type, or notes.
- Filter or group by issue type; optionally group by address code.
- Sort errors first, improve table readability, and provide clear empty states.
- Preserve previous results on upload failure and improve processing/error feedback.

## Later
- Add next/previous issue navigation, collapsible groups, and responsive, keyboard-accessible tables.
- Place the required history and CSV export actions near the summary; make export scope clear.

Prioritize validators, history, and export over visual polish, per the assignment.
